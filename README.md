# Arduino-Quiz-Game
This project is an Arduino-based quiz game that I developed while learning Arduino and embedded systems.
The player answers questions using buttons. The system checks the answers and gives feedback using an LCD display, LEDs and a buzzer. After the required steps are completed successfully, a servo motor controls the locking mechanism.

## Components
- Arduino Uno
- 16x2 LCD with I2C
- Push buttons
- LEDs
- Buzzer
- SG90 servo motor
- Breadboard
- Resistors and jumper wires

  ## Features
- LCD-based question display
- Button-controlled answers
- Answer checking
- Password memory system
- LED feedback
- Buzzer feedback
- Servo-controlled locking mechanism

  ## Development
  I developed the project step by step while learning Arduino.
  The final version combines button input, answer checking, LCD output, LED and buzzer feedback, password functionality and servo control into one complete system.
